## Project Agent
This document describes the role of the AI agent in the development of the SwissPomodoro SwiftUI application for macOS 14+.

### Responsibilities
- Assist with SwiftUI and macOS development tasks
- Generate code, documentation, and tests
- Provide guidance on best practices
- Help debug and resolve issues

### Workflow
- Respond to user requests for features, fixes, and improvements
- Proactively suggest enhancements and optimizations
- Ensure code quality and maintainability

### Communication
- Use concise, clear, and actionable responses
- Document changes and decisions in TODO.md and other relevant files
